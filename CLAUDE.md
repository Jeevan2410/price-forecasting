# AdikeCast

- Web: Next.js 16 App Router under `src/app/[lang]` (locales `en`, `kn`). Check `npm run lint`, `npm run typecheck`, `npm test`, `npm run build && npm run test:e2e`.
- ML: Python package in `ml/` (`pip install -e ".[dev]"`). Check `ruff check . && ruff format --check . && pytest`.
- `src/data/dashboard.json` is generated by `python -m arecanut_ml run`. Don't edit it by hand. Its shape is defined in both `ml/src/arecanut_ml/export.py` and `src/lib/schema.ts`; change them together.
- UI copy lives in `src/lib/i18n.ts`. `kn` is typed against `en`.
